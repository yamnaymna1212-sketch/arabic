# The Money Trail

English US personal-finance channel: **"What happens if…?"** stories that follow one
American character, Tyler, step by step, in a cinematic style.

- `channel/CHANNEL.md`: channel guide (episode structure, character, location library, workflow, episode ideas)
- `episodes/ep01-car-loan/`: Episode 1 script: *What Happens If You Stop Paying Your Car Loan?*
- `money-trail-video/`: Remotion project that renders the episodes, thumbnails, logo and banner
